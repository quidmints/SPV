QU!D dead-man watchtower

Keyless BTC recovery. If the QU!D fleet goes dark, the fully-signed unilateral-exit transaction is already public in the on-chain DeadManExitEmitted event. This page reads it and — once its CLTV timelock has matured — broadcasts the raw bytes to a public Bitcoin mempool. No wallet, no key, no signing.

Security: read-only EVM reads + a public Bitcoin broadcast. It cannot redirect funds — the payout is pinned to the LP's btcRecipientOf inside the already-signed bytes. Broadcasting before maturity just wastes a POST (the mempool rejects a non-final tx). Nothing sensitive is ever handled here. Host this file anywhere (IPFS, a gist, a USB stick); run several copies for redundancy.
